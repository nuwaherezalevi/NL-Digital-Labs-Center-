# NL Digital Labs Center Website

Responsive static website prototype for NL Digital Labs Center, Bushenyi, Uganda.

## Files
- `index.html` — homepage and page sections
- `styles.css` — responsive styling, colors, layouts, focus states and reduced-motion support
- `script.js` — mobile menu, service request flow, feedback email flow, and demo client login modal
- `assets/founder.jpg` — supplied founder portrait
- `assets/digital-lab-team.png` — supplied computer lab/team image used in the hero and training section

## Run locally
Open `index.html` in a browser. For best testing, use a simple static web server or deploy the folder to a static hosting provider.

## Important before launch
This is a front-end prototype. The client login panel is **not connected to real authentication** and must not be used with real passwords. For a production client portal, connect a secure backend/authentication provider, database, protected file storage, password reset, access controls and HTTPS. Service requests open WhatsApp with pre-filled details; users must press Send. Feedback opens the visitor's email app; no messages are stored by this static website.

The contact page lists Bushenyi, Uganda; add the exact street/landmark, opening hours, approved prices and any real customer testimonials before launch. Configure a domain and HTTPS through the chosen hosting provider.
